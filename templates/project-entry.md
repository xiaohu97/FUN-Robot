# 开源项目条目模板

复制以下表格行，加入 [`projects/README.md`](../projects/README.md) 对应分类：

```markdown
| [项目名](https://github.com/org/repo) | 类型 | 一句话：能做什么、适合谁 | `标签1` `标签2` | 高/中/低 |
```

| 字段 | 规范 |
|---|---|
| 类型 | 框架 / 仿真器 / 策略模型 / SDK / 数据集工具 / 基准 |
| 一句话 | 中文 ≤ 50 字，说清“用它可以做什么” |
| 标签 | 从 [`taxonomy.md`](../taxonomy.md) 选 |
| 上手难度 | 高 / 中 / 低（文档、依赖、硬件要求综合判断） |
