# 论文条目模板（加入分类清单用）

> 用途：往 `papers/NN-*.md` 的表格里新增**一行**。
> 精读过的论文，再用 [`paper-note.md`](./paper-note.md) 写一篇笔记，并在本行「资源」列挂上 `[笔记]` 链接。

## 1. 复制这一行，填进对应分类文件的「🏛 经典论文」或「🚀 最新进展」表格

```markdown
| ⭐ **简称** · 英文全称 | 2026 · 会议/arXiv | 一句话说清：解决什么问题 + 用什么方法 + 关键结果 | [arXiv](https://arxiv.org/abs/XXXX.XXXXX) · [代码](https://github.com/org/repo) · [主页](https://...) · [笔记](./notes/XXXX.XXXXX-short-name.md) |
```

也可以用脚本自动生成这一行（会尝试联网拉取 arXiv 标题）：

```bash
python scripts/new_paper.py 2303.04137 --short "Diffusion Policy" --topic 03
```

## 2. 字段规范

| 字段 | 必填 | 规范 |
|---|---|---|
| ⭐ | 否 | 仅「领域必读 / 开创范式」的论文加 ⭐，每个分类不超过 1/3 |
| 简称 | 是 | 社区通用叫法，如 `RT-2`、`π0`、`ACT`；没有简称就用标题前几个词 |
| 英文全称 | 是 | 与 arXiv 标题一致，方便检索 |
| 年份 · 会议 | 是 | 首次公开年份；已中稿写 `CoRL'24` / `RSS'25` / `Science Robotics`，未中稿写 `arXiv` |
| 一句话贡献 | 是 | 中文，≤ 60 字。格式建议：「做了什么 → 怎么做 → 为什么重要」 |
| 资源 | 是 | 至少一个论文链接；arXiv 统一用 `https://arxiv.org/abs/编号`（**不带版本号 v1/v2**） |

## 3. 放在哪里？

- **经典 vs 最新**：发表超过 2 年、且已被广泛引用/复现 → 「🏛 经典论文」；近 2 年 → 「🚀 最新进展」。每年初把老化的「最新进展」挪到「经典」或删掉。
- **只放一个主分类**：一篇论文只在一个分类文件出现（`scripts/check.py` 会检查重复）；跨方向的论文选其「最核心贡献」所在分类，并在 [`taxonomy.md`](../taxonomy.md) 的标签里体现交叉。
- **表格内排序**：按年份升序；同年份按重要性。
- **月度新论文**：先进 `digests/YYYY-MM-*.md`（周报/月报，用 [`digest.md`](./digest.md) 模板），确认值得长期保留的再“升级”进分类清单。
