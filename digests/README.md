# 🗞 最新进展速递（按时间）

分类清单（`papers/`）回答“这个方向有哪些重要论文”，速递回答“最近发生了什么”。
每期一份文件，命名 `YYYY-MM-主题.md`（跨月用 `YYYY-MM-MM-主题.md`），模板见 [`templates/digest.md`](../templates/digest.md)。

## 工作流
1. **收集**：arXiv `cs.RO` 每日列表、关注的实验室主页 / 博客、模型发布；
2. **整理**：按模板填写本月 Top 5、趋势观察、分方向清单；
3. **升级**：值得长期保留的论文，用 `scripts/new_paper.py` 写进 `papers/NN-*.md` 的「🚀 最新进展」表格，并在速递末尾勾选 `⬆️ 升级到长期清单`。
